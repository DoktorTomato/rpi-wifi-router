# Курсова робота: Wi-Fi Router на базі Raspberry Pi

## Мета
Розробити Wi-Fi маршрутизатор на базі Raspberry Pi та Linux із власним Web UI для керування мережевими функціями.
Реалізувати керування конфігурацією та автоматизувати підготовку системи.

## Функціональні вимоги

**1. Мережеві режими**
- **Router / Access Point:** Ethernet — WAN, Wi-Fi — LAN, підтримка routing, NAT, DHCP, DNS cache, port forwarding (через UI).
- **Bridge:** L2-з'єднання між Ethernet і Wi-Fi.
- **Station:** підключення до існуючої Wi-Fi мережі як клієнт і її "розширення" через Ethernet.

**2. Web UI**
- Перегляд стану мережевих інтерфейсів.
- Налаштування режимів роботи, IP-адресації та Wi-Fi.
- Quick Setup Wizard для початкового налаштування.

**3. Керування конфігурацією**
- Збереження та відновлення конфігурації після перезавантаження.
- Перевірка параметрів перед застосуванням.
- Factory Reset із поверненням до початкового стану.
- Механізм відновлення доступу в разі помилкової конфігурації.

**4. IoT Isolation**
- Створення окремого сегмента для IoT-пристроїв.
- Обмеження доступу IoT до основної локальної мережі.
- Обґрунтування політик доступу та їхніх обмежень.

**5. Автоматизована збірка Linux**
- "Прошивка" вашого роутера має мати чіткі кроки підготовки, які піддаються автоматизації.

## Очікуваний результат
Після встановлення образу користувач повинен мати можливість налаштувати маршрутизатор через Quick Setup Wizard, перемикати режими роботи, керувати мережею через Web UI, зберігати та скидати конфігурацію.

- Де і для кого використовуються такі рішення.
